AI Page Translator 導入マニュアル

生成AI（Gemini・ChatGPT・Claude など）で、Web ページ全体を日本語に翻訳する Google Chrome の拡張機能です。

  1. 用意するもの
  2. 拡張機能を Chrome に入れる
  3. APIキーを用意する（Gemini の場合）
  4. 設定する
  5. ローカルLLMで使う（APIキー不要・無料）
  6. 使い方
  7. 困ったとき
  8. 更新・削除のしかた

1. 用意するもの

  • パソコン版の Google Chrome（Windows / Mac）
  • 翻訳に使う AI の APIキー（どれか1つ）
    AI料金APIキーの取得先
    Google Gemini無料枠あり（おすすめ）Google AI Studio
    OpenAI（ChatGPT）有料（使った分だけ）OpenAI Platform
    Anthropic（Claude）有料（使った分だけ）Anthropic Console
    ChatGPT や Claude の月額プラン（Plus / Pro など）とは別契約です。月額プランに入っていても API は使えません。

APIキーを使わずに、自分のパソコンの中で動く AI（ローカルLLM）で翻訳することもできます。5. ローカルLLMで使う を見てください。

2. 拡張機能を Chrome に入れる

  1. 受け取った ai-page-translator.zip を展開（ダブルクリック、Windows では右クリック →「すべて展開」）します。
  2. できた ai-page-translator フォルダを、消さない場所（「書類」「ドキュメント」など）に移します。
    Chrome はこのフォルダから拡張機能を読み込み続けるので、フォルダを消したり動かしたりすると使えなくなります。
  3. Chrome のアドレスバーに chrome://extensions と入力して開きます。
  4. 右上の 「デベロッパー モード」をオンにします。
  5. 左上に出てくる 「パッケージ化されていない拡張機能を読み込む」を押し、さきほどの ai-page-translator フォルダを選びます。
    （中に manifest.json が入っているフォルダです。その1つ外側や内側のフォルダを選ぶと読み込めません。）
  6. 一覧に「AI Page Translator」が出れば完了です。
  7. 使いやすいように、ツールバーのパズルのアイコン（拡張機能）を押し、AI Page Translator の横のピンを押して、ツールバーに固定しておきます。
Chrome を起動したときに「デベロッパー モードの拡張機能を無効にする」などの案内が出ることがあります。Chrome ウェブストア以外から入れた拡張機能に出るもので、そのまま閉じて大丈夫です。

3. APIキーを用意する（Gemini の場合）

  1. Google AI Studio の APIキーのページ を開き、Google アカウントでログインします。
  2. 「APIキーを作成」（Create API key）を押します。
  3. 表示されたキー（AIza… で始まる長い文字列）をコピーします。
APIキーはパスワードと同じです。他の人に教えたり、SNS などに貼ったりしないでください。

4. 設定する

  1. ツールバーの AI Page Translator のアイコンを押し、出てきた画面の設定へのリンクを押します。
    （または chrome://extensions の AI Page Translator の「詳細」→「拡張機能のオプション」）
  2. プロバイダで使う AI を選びます（例: Google Gemini）。
  3. APIキーにコピーしたキーを貼り付けます。
  4. モデルは最初から入っているもののままで大丈夫です。
  5. 「保存」を押し、続けて「接続テスト」を押します。訳文の例が表示されれば準備完了です。

その他の設定（必要なときだけ）

設定内容
翻訳先言語最初は「日本語」。英語にしたいときは「英語」などに変えます。
クリックした先のページも自動で翻訳する翻訳したタブでリンクを押して移った先も、自動で翻訳します。保存するときに「すべてのサイトへのアクセス」の許可を求められるので、「許可」を押してください。
サイトの翻訳禁止指定を無視して翻訳する見出しなど一部が翻訳されないサイトで使います。レイアウトが崩れることがあります。
1バッチの最大文字数 / 同時リクエスト数ふつうは変えなくて大丈夫です。Gemini の無料枠で待ち時間が長いときは、最大文字数を 8000 くらいに増やすと、送る回数が減ります。

5. ローカルLLMで使う（APIキー不要・無料）

LM Studio や Ollama というアプリを使うと、AI を自分のパソコンの中で動かして翻訳できます。

  • よいところ: APIキーも料金も要りません。ページの文章がパソコンの外に送られないので、社外秘のページにも使えます。利用上限もありません。
  • 気をつけること: パソコンの性能が必要で、クラウドの AI より遅く、訳の質も少し落ちます。メモリ（RAM）は 16GB 以上がおすすめです。
メモリおすすめのモデル
16GB 以上Gemma 3 12B（LM Studio: google/gemma-3-12b / Ollama: gemma3:12b）
8GBGemma 3 4B（LM Studio: google/gemma-3-4b / Ollama: gemma3:4b）。軽いぶん、訳が崩れることが増えます。

LM Studio と Ollama のどちらか一方を入れれば使えます。画面で操作できる LM Studio のほうが簡単です。

A. LM Studio を使う（おすすめ）

  1. lmstudio.ai から LM Studio をダウンロードしてインストールします（Windows / Mac）。
  2. LM Studio を開き、左の虫めがねのアイコン（Discover）で gemma-3-12b を検索して、ダウンロードします。
  3. 左の「Developer」（開発者）の画面を開き、上の 「Status: Stopped」のスイッチをオンにして、サーバーを起動します（「Running」になればOK）。
    あわせてモデルを選んで読み込んでおくと、最初の翻訳が速く始まります。
  4. 拡張機能の設定画面で、プロバイダを「LM Studio（ローカル）」にします。
  5. モデルに google/gemma-3-12b と入力します（LM Studio のモデル名の欄に出ている名前と同じにします）。
  6. アドレスは http://localhost:1234/v1 のままにします。
  7. 「保存」→「接続テスト」を押し、訳文の例が出れば完了です。
設定画面に「モデル一覧を取得できませんでした」と出ても、モデル名を手で入力すれば使えます（一覧の表示には、下の「自動起動の準備」が必要です）。
翻訳するときは、毎回 LM Studio を開いてサーバーを起動しておいてください。

LM Studio を自動で起動する（Mac のみ・任意）

Mac では、準備をしておくと、翻訳するときに LM Studio のサーバーの起動とモデルの読み込みを自動でやってくれます。Windows ではこの機能は使えないので、上の手順のとおり自分で起動してください。

  1. LM Studio を一度起動しておきます（lms コマンドが使えるようになります）。
  2. 「ターミナル」アプリを開き、次のように入力して Enter を押します。
    sh と入力したあと（最後に半角スペースを入れる）、ai-page-translator フォルダの中の native-host フォルダにある install.sh をターミナルの画面にドラッグすると、場所が自動で入ります。
    例: sh ~/Documents/ai-page-translator/native-host/install.sh
  3. 「Python 3.8 以上が必要です」と出たら、python.org から Python をインストールして、もう一度実行します。
  4. chrome://extensions で AI Page Translator の再読み込みボタン（↻）を押します。
  5. 設定画面の「LM Studio を自動で起動する」にチェックが入っていることを確かめます。

やめるときは、同じ場所の uninstall.sh を同じように実行します。

B. Ollama を使う

  1. ollama.com から Ollama をダウンロードしてインストールし、起動します。
  2. ターミナル（Windows では「ターミナル」または「コマンド プロンプト」）で ollama pull gemma3:12b を実行して、モデルをダウンロードします。
  3. 拡張機能の設定画面で、プロバイダを「OpenAI互換 / ローカルLLM」にします。
  4. ベースURLは http://localhost:11434/v1、モデルは gemma3:12b にします。APIキーは空のままで大丈夫です。
  5. 「保存」→「接続テスト」を押します。
接続テストで「ローカルサーバーが拒否しました (403)」と出たら、Ollama に「拡張機能からの接続を許可する」設定が必要です。
Mac: ターミナルで launchctl setenv OLLAMA_ORIGINS "chrome-extension://*" を実行し、Ollama を終了して起動し直します。
Windows: 「システム環境変数の編集」→「環境変数」で、ユーザー環境変数に 名前 OLLAMA_ORIGINS・値 chrome-extension://* を追加し、Ollama を終了して起動し直します。

6. 使い方

  1. 翻訳したいページを開きます。
  2. ツールバーの AI Page Translator のアイコンを押し、「翻訳」を押します。
  3. ページの文章が順に日本語に置き換わります。ページの右下に進み具合が表示されます。
  • 「停止」: 翻訳を途中で止めます。
  • 「原文に戻す」: 元の文章に戻します。
  • スクロールして新しく出てきた文章も、自動で翻訳されます。
  • 一度訳した文章は保存されるので、同じページをもう一度訳すときは速く、AI の利用量もほとんど使いません。
クラウドの AI（Gemini・ChatGPT・Claude）を選んでいるときは、ページの文章がその会社（Google・OpenAI・Anthropic）に送られます。社外秘の資料や個人情報が載ったページでは、ローカルLLMを使ってください。APIキーと設定は、そのパソコンの Chrome の中だけに保存されます。

7. 困ったとき

表示・症状対処
「APIキーを確認してください (401 / 403)」キーが間違っています。コピーし直して貼り付け、「保存」を押してください。
「利用上限のため ○秒待ってから続けます…」Gemini の無料枠の「1分あたりの上限」です。そのまま待てば自動で続きます。
「Gemini の無料枠の1日の上限に達しました」その日の無料分を使い切りました。日本時間の夕方（16〜17時ごろ）に回復します。
「APIの利用上限（クォータ）に達しました」OpenAI / Anthropic の場合は、残高や支払い設定を確認してください。
「サーバーエラー (503)」AI の会社のサーバーが混んでいます。少し待ってからもう一度「翻訳」を押してください。
「翻訳完了（○件失敗）」もう一度「翻訳」を押すと、失敗した部分だけ訳し直します。
「このページは翻訳できません」Chrome の設定画面（chrome:// で始まるページ）、ウェブストア、PDF は翻訳できません。
一部の見出しなどが翻訳されない設定の「サイトの翻訳禁止指定を無視して翻訳する」をオンにしてください。
「ローカルLLMに接続できません」LM Studio のサーバー（または Ollama）が起動していません。起動してからもう一度試してください。
ローカルLLMで、訳が崩れる・一部が訳されない小さいモデルで起きやすいです。もう一度「翻訳」を押すか、大きいモデル（12B など）に変えてください。
アイコンを押しても何も起きないページを再読み込みしてから、もう一度試してください。

8. 更新・削除のしかた

新しい版に更新する

  1. 新しい zip を展開し、今の ai-page-translator フォルダの中身を、新しいものに入れ替えます（フォルダの場所は変えないでください）。
  2. chrome://extensions を開き、AI Page Translator の再読み込みボタン（↻）を押します。設定はそのまま残ります。

削除する

chrome://extensions で AI Page Translator の「削除」を押し、そのあと ai-page-translator フォルダを消します。

詳しい人向け

  • OpenAI互換のサーバー（OpenRouter や vLLM など）も「OpenAI互換 / ローカルLLM」で使えます。詳しくはフォルダ内の README.md を見てください。
